## 缺陷列表

### BUG-01 `SellerController.me()` 未实现，登录后拿不到卖家信息
- **严重级**：中
- **所属模块**：后端卖家接口（`controller/SellerController.java:46`）
- **指派**：李帆
- **现象**：`GET /api/seller/me` 校验 session 后 `return Result.success(null)`，data 恒为 null。
- **复现步骤**：登录成功后调用 /me，响应 data=null，而预期返回当前登录卖家信息（不含密码）。
- **状态**：待修复

### BUG-02 `POST /api/product/publish` 无登录校验
- **严重级**：高
- **所属模块**：后端商品接口（`controller/ProductController.java:27`）
- **指派**：李帆
- **现象**：发布商品接口未校验 `HttpSession`，未登录状态也能发布商品。
- **影响**：违反 UC-07「发布商品（卖家后台）需卖家登录」。
- **复现步骤**：不带 session 直接 POST /api/product/publish，仍返回 code=200。
- **状态**：待修复

### RISK-01 登录密码明文比对
- **严重级**：风险（非本迭代缺陷）
- **所属模块**：后端卖家服务（`service/SellerService.java:32`）
- **说明**：迭代 2 暂用明文比对，已注明「后续迭代接入 BCrypt」。建议迭代 3/4 前引入 BCrypt 加密存储。
- **状态**：待办

### NOTE-01 `getOnSaleProduct()` 使用 `selectOne`
- **严重级**：低（备注）
- **所属模块**：后端商品服务（`service/ProductService.java:63`）
- **说明**：`selectOne` 在出现多行在售时（单件约束被绕过或历史遗留数据）会抛异常，建议后续加 `LIMIT 1` 或先按约束保障数据唯一。
- **状态**：观察
